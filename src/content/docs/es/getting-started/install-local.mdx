Instalar en local sigue los mismos pasos que cualquier otra instalación. Lo que cambia es cómo obtienes PHP y MySQL.

## macOS

1. Instala [Homebrew](https://brew.sh/).
2. Instala PHP y una base de datos:

   ```bash
   brew install php composer
   brew install mariadb   # or: brew install mysql
   ```

3. Inicia el servidor integrado de PHP desde la carpeta de PHPNuxBill:

   ```bash
   php -S localhost:8000
   ```

   El servidor integrado no lee `.htaccess`, así que las URL amigables necesitan una configuración de Apache o Nginx. Abrir `/index.php?_route=...` funciona sin ella.

## Windows

1. Instala [XAMPP](https://www.apachefriends.org/index.html) o [Laragon](https://laragon.org/).
2. Inicia Apache y MySQL desde el panel de control.
3. Coloca los archivos de PHPNuxBill en `htdocs` (XAMPP) o `www` (Laragon).
4. Abre `http://localhost/your-folder` y ejecuta el instalador.

Programar tareas cron es más difícil en Windows. Usa el Programador de tareas, o una máquina Linux para cualquier cosa más allá de probarlo.
