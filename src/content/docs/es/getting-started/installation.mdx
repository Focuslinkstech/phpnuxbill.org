## Requisitos

| Necesario | Notas |
|---|---|
| PHP 8.2 o superior | con las extensiones PDO y MySQLi |
| MySQL | la base de datos en la que el instalador importa los datos |
| GD2, cURL, ZIP, mbstring | extensiones de PHP |
| Un servidor web | Apache con `mod_rewrite`, o cualquier servidor que envíe las rutas desconocidas a `index.php` |

Se recomienda Linux. En Windows funciona, pero programar el cron es más difícil.

También funciona en una Raspberry Pi.

### Para producción

| | Recomendado | Mejor rendimiento |
|---|---|---|
| Servidor | VPS o servidor dedicado | VPS o servidor dedicado |
| CPU | 1 GHz o más | Cuatro núcleos, 3 GHz o más |
| RAM | 1 GB o más | 6 GB o más |
| Disco | 10 GB o más | 200 GB o más |
| Red | 50 Mbps o más | 100 Mbps o más, preferiblemente 1 Gbps |

Ambos necesitan Linux, PHP 8.2 o superior, MariaDB 10 o superior, Apache 2.4 con `mod_rewrite` o Nginx, un certificado SSL (Let's Encrypt es gratuito) y estas extensiones de PHP: bcmath, curl, gd, intl, mbstring, mysqli, pdo, tokenizer, xml y zip.

FreeRADIUS es opcional y necesita su propio VPS o servidor dedicado.

## Instalar

1. **Sube los archivos.** La raíz del repositorio es la raíz web. No hay carpeta `public/`.
2. **Crea una base de datos vacía** y un usuario para ella.
3. **Abre `/install`** en el navegador. El instalador escribe `config.php` e importa `install/phpnuxbill.sql`.
4. **Inicia sesión** con la cuenta que creaste y añade tu router en *Network*.

> `config.php` contiene las credenciales de la base de datos y `APP_URL`. No forma parte del repositorio; `config.sample.php` es la plantilla.

## Cron

Los planes se vencen y se renuevan, y los recordatorios se envían, mediante una tarea cron. Sin ella, los clientes siguen conectados cuando su plan termina.

```bash
# cada minuto: vence y renueva a los clientes
* * * * * cd /path/to/site/system && php cron.php

# cada día: envía recordatorios
0 8 * * * cd /path/to/site/system && php cron_reminder.php
```

Otras tareas que puedes añadir del mismo modo:

```bash
php system/cron/clean_expired_vouchers.php
php system/cron/cleanup_stale_sessions.php
php system/cron/marketplace_sync.php
```

El panel te avisa cuando el cron lleva más de 24 horas sin ejecutarse.

## Actualizar

Después de subir una versión nueva, abre `/update.php`. Reproduce las nuevas sentencias del esquema desde `system/updates.json` y escribe `version.json`. Haz antes una copia de seguridad de la base de datos.

## Desarrollo local

Apunta un servidor PHP local o un virtual host de XAMPP a la raíz del repositorio. Cuando `$_app_stage` en `config.php` no es `Live`, se muestran los errores y se registran las consultas, que es lo que quieres en una máquina de desarrollo y no en producción.
