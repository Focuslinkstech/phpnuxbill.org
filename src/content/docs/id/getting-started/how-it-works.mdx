PHPNuxBill awalnya dibuat untuk menjual voucher. Anda membuat voucher di PHPNuxBill lalu menjualnya ke pelanggan. Voucher tidak pernah masuk ke Mikrotik. Sebagai gantinya, template login di router mengarahkan pelanggan ke PHPNuxBill untuk mendaftar. Pelanggan membeli voucher, mendaftar, lalu mengaktifkannya di PHPNuxBill. PHPNuxBill kemudian menambahkan pelanggan ke Mikrotik, dan pelanggan masuk lewat halaman login router dengan akun PHPNuxBill mereka.

Payment gateway dan pendaftaran yang mudah mengubah hal ini. Voucher kini hanya salah satu pilihan: pelanggan bisa membeli paket langsung lewat payment gateway di PHPNuxBill.
