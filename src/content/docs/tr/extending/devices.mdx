Sürücü tek bir sınıftır. Faturalama motoru onu yapıcı argümanı olmadan oluşturur (`new $plan['device']`), bu yüzden sınıf adı
dosya veya klasör adıyla aynı olmalıdır. Bir paket sürücüsünü paket formunda seçer.

| Metot | Ne zaman çağrılır |
|---|---|
| `description()` | Cihaz listesinin bir başlığa, yazara ve bağlantılara ihtiyacı olduğunda. |
| `add_customer($customer, $plan)` / `remove_customer($customer, $plan)` | Bir müşteri etkinleştirildiğinde veya süresi dolduğunda. |
| `change_username($plan, $from, $to)` | Bir kullanıcı adı değiştiğinde. |
| `add_plan($plan)` / `update_plan($old_name, $plan)` / `remove_plan($plan)` | Bir paket oluşturulduğunda, düzenlendiğinde veya silindiğinde. |
| `connect_customer(...)` / `online_customer(...)` / `disconnect_customer(...)` | Hotspot girişi, durumu ve çıkışı. |
| `sync_customer($customer, $plan)` | İsteğe bağlı. Etkin bir müşteriyi cihaza yeniden gönderir. |

Kullanılmayan metotları silmek yerine boş bırakın.

```php
class AcmeRouter
{
    public function description()
    {
        return ['title' => 'Acme Router', 'description' => 'Drives Acme routers.', 'author' => 'You'];
    }
```

Çekirdek sürücüler (`MikrotikHotspot`, `MikrotikPppoe`, `MikrotikStatic`, `MikrotikVpn`, `Radius`, `RadiusALE`, `RadiusChillispot`,
`RadiusRest`, `Voucher`, `Dummy`) yükleme ile değiştirilemez ve paketlerin hâlâ kullandığı bir sürücü kaldırılamaz.
`$_app_stage` değeri `Demo` iken gerçek cihazlara dokunmayın.
