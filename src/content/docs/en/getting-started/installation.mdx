## Requirements

| Needed | Notes |
|---|---|
| PHP 8.2 or newer | with the PDO and MySQLi extensions |
| MySQL | the database the installer imports into |
| GD2, cURL, ZIP, mbstring | PHP extensions |
| A web server | Apache with `mod_rewrite`, or any server that sends unknown paths to `index.php` |

Linux is recommended. Windows works, but scheduling the cron job there is harder.

It also runs on a Raspberry Pi.

### For production

| | Recommended | Better performance |
|---|---|---|
| Server | VPS or dedicated server | VPS or dedicated server |
| CPU | 1 GHz or faster | Quad core, 3 GHz or faster |
| RAM | 1 GB or more | 6 GB or more |
| Disk | 10 GB or more | 200 GB or more |
| Network | 50 Mbps or more | 100 Mbps or more, 1 Gbps preferred |

Both need Linux, PHP 8.2 or newer, MariaDB 10 or newer, Apache 2.4 with `mod_rewrite` or Nginx, an SSL certificate (Let's Encrypt is free), and these PHP extensions: bcmath, curl, gd, intl, mbstring, mysqli, pdo, tokenizer, xml and zip.

FreeRADIUS is optional and needs its own VPS or dedicated server.

## Install

1. **Upload the files.** The repository root is the web root. There is no `public/` folder.
2. **Create an empty database** and a user for it.
3. **Open `/install`** in your browser. The installer writes `config.php` and imports `install/phpnuxbill.sql`.
4. **Sign in** with the account you created and add your router under *Network*.

> `config.php` holds the database credentials and `APP_URL`. It is not part of the repository; `config.sample.php` is the template.

## Cron

Plans are expired and renewed, and reminders are sent, by a cron job. Without it customers stay online after their plan ends.

```bash
# every minute: expire and renew customers
* * * * * cd /path/to/site/system && php cron.php

# every day: send reminders
0 8 * * * cd /path/to/site/system && php cron_reminder.php
```

Other jobs you can add the same way:

```bash
php system/cron/clean_expired_vouchers.php
php system/cron/cleanup_stale_sessions.php
php system/cron/marketplace_sync.php
```

The dashboard warns you when the cron job has not run for 24 hours.

## Updating

After you upload a newer version, open `/update.php`. It replays the new schema statements from `system/updates.json` and writes
`version.json`. Take a database backup first.

## Local development

Point a local PHP server or an XAMPP virtual host at the repository root. When `$_app_stage` in `config.php` is not `Live`,
errors are displayed and queries are logged, which is what you want on a development machine and not in production.
