PHPNuxBill is free software, and help is given by the community, for free.

## Where to ask

- **[The forum](https://forum.phpnuxbill.org)**: best for questions that other people will search for later.
- **[The Telegram group](https://t.me/phpnuxbill)**: quick back-and-forth.
- **[The Facebook group](https://web.facebook.com/groups/1404570750225597/)**: for people who already use Facebook groups.
- **[GitHub Discussions](https://github.com/hotspotbilling/phpnuxbill/discussions)**: questions and ideas that belong next to the code.

Before you post, search: your question has often been asked already.

## What to include

A good question gets a fast answer. Say:

1. **What you were trying to do**, in a sentence.
2. **What happened instead**, with the exact error text if there is one. You can read errors on a test machine by setting `$_app_stage` in `config.php` to something other than `Live`, and in the admin *Logs* page.
3. **Your versions**: PHPNuxBill (see `version.json`), PHP, and the RouterOS version if the router is involved.
4. **What you already tried.**
5. **A screenshot**, if it is about how something looks. Hide passwords, tokens and customers' personal details first.

Never post `config.php`, API keys or router passwords.

## Prefer hands-on help?

Paid support starts from 100 USD. See the [support page](/support/).

## Found a bug or want a feature?

Open a discussion on GitHub with the same details. If you can fix it, a pull request is even better. Translations of this website are welcome too: every docs page has an *Edit this page on GitHub* link.
