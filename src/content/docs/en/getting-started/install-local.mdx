Installing locally follows the same steps as any other install. What changes is how you get PHP and MySQL.

## macOS

1. Install [Homebrew](https://brew.sh/).
2. Install PHP and a database:

   ```bash
   brew install php composer
   brew install mariadb   # or: brew install mysql
   ```

3. Start PHP's built-in server from the PHPNuxBill folder:

   ```bash
   php -S localhost:8000
   ```

   The built-in server does not read `.htaccess`, so pretty URLs need an Apache or Nginx setup. Opening `/index.php?_route=...` works without one.

## Windows

1. Install [XAMPP](https://www.apachefriends.org/index.html) or [Laragon](https://laragon.org/).
2. Start Apache and MySQL from the control panel.
3. Put the PHPNuxBill files in `htdocs` (XAMPP) or `www` (Laragon).
4. Open `http://localhost/your-folder` and run the installer.

Cron jobs are harder to schedule on Windows. Use Task Scheduler, or a Linux machine for anything beyond trying it out.
