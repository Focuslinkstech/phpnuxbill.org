لكل حساب موظف دور واحد. يحدد الدور عناصر القائمة التي تظهر والصفحات التي تُفتح.

| الدور | الاستخدام المعتاد |
|---|---|
| `SuperAdmin` | المالك. صلاحيات كاملة تشمل إعدادات النظام. |
| `Admin` | الإدارة اليومية للعملاء والباقات والراوترات. |
| `Report` | وصول للقراءة فقط إلى التقارير. |
| `Agent` | موزّع يبيع لعملائه. |
| `Sales` | المبيعات عند المكتب الأمامي. |
| `Asset` | المعدات والمخزون. |
| `Support` | دعم العملاء. |

## لوحة تحكم لكل دور

يُحفظ تخطيط لوحة التحكم لكل دور، فقد يرى مستخدم `Support` عناصر مختلفة عمّا يراه `Admin`.

## تقييد صفحة في الكود

تفحص المتحكمات والإضافات الدور مباشرة:

```php
if (!in_array($admin['user_type'], ['SuperAdmin', 'Admin'])) {
    _alert(Lang::T('You do not have permission to access this page'), 'danger', 'dashboard');
}
```

تأخذ عناصر القائمة التي تضيفها الإضافات القائمة نفسها في وسيط `auth`. القائمة الفارغة تعني الجميع.
